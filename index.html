Built for writing, not for accounts

Everything you need. Nothing you have to manage.

Neurix keeps its feature set close to the page, no dashboards, no settings you'll never touch.

Markdown, edited and previewed

Write in plain Markdown and switch to a rendered preview instantly, in the same window.

Search that stays instant

Everything is local, so search never waits on a network round trip. Find a note the moment you type.

Pin what matters today

Keep the notes you're actively using at the top, without folders or a filing system to maintain.

Drag and drop images

Pull an image straight into a note. It's saved alongside your text, right on your own disk.

Encrypted with Windows DPAPI

Notes are encrypted using the same protection Windows uses for your credentials, no extra password to remember.

Light, dark, or your own

Pick a built-in theme or design your own palette. The app looks like your app.

Writing feels like writing

Type in Markdown. Read it as a page.

Neurix supports the syntax you already know, plus a few conveniences for linking your own thinking together.

No cloud to trust, none to leave

Your notes never leave your computer.

Not because Neurix is missing a sync feature, because it was never built to need one.

  • Storage Notes are saved as plain Markdown files, directly on your disk.
  • Encryption Windows DPAPI protects your notes using your own Windows login.
  • Connection Neurix runs fully offline, there's no server for it to talk to.
  • Accounts None. Nothing to sign up for, nothing to lose access to.
Ready when you are
